# tests 目录

| 文件 | 用途 |
|---|---|
| `offline_check.py` | 🔴 离线自检：不联网、不需要模型服务即可验证核心逻辑 |

⏳ **本目录目前只有这份说明。** `offline_check.py` 由 C₂ 在第 5 步创建 ——
在建库与数据访问层落地之后，才有东西可测。

## 为什么必须有

官方评分维度包含「是否有基本的测试或自检手段」。

这份脚本同时是**队友接手时的体检报告** —— 跑一遍就知道哪里坏了，比读代码快得多。

## 覆盖范围

- **数据完整性**：知识点与题库是否加载、有无指向不存在条目的孤儿引用
- **掌握度查询的三个边界**：没练过的是否出现、除零处理、样本不足的排序位置、NULL 是否沉底
- **两个校验器的畸形输入**：错题抽取与练习出题分别覆盖（清单见 `docs/interfaces.md` 第六节）
- **判分逻辑**：选对、选错、大小写宽容、填空等价写法
- **配置缺失**：未设密钥时给出清晰错误提示而不是崩溃

## 用法

```bash
python tests/offline_check.py     # 期望全部通过、退出码 0
```

🔴 每天开工先跑一次 —— 红了说明主干是坏的，先报告别硬写新功能。

⚠️ 脚本开头必须加：

```python
import sys
sys.stdout.reconfigure(encoding="utf-8")
```

否则中文 Windows 控制台打印 emoji 会抛 `UnicodeEncodeError`，导致退出码 1。

另外：改完脚本要同步更新 README 和其他文档里引用的"N 项"数字，保持一致。

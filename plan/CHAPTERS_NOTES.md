# data/chapters.json 说明

🔴 **这不是知识点库**，只是若干「归类抽屉」的名字（当前 15 个）。具体知识点（洛必达法则、分部积分法…）
由系统在问答和错题归类时通过 `find_or_create()` 自动创建并挂到这里。

设这个上限的唯一原因：不给顶层分类设边界，AI 会造出「极限」「函数极限」「求极限」
「洛必达」这种粒度并列的条目，掌握度统计随即作废。

## id 命名规范

```
格式：ch_<英文关键词>
规则：全小写、下划线分隔、不用中文
```

🔴 id 出现在数据文件 / 表结构 / 提示词 / 校验器四处，中途改名代价极大 —— 上线后不再改。

## brief 字段怎么写

`brief` 会被注入提示词，作为模型判断「这道题该挂哪一章」的判据。
所以它只需要**内容关键词**：

```
✅ 定积分概念与性质、微积分基本公式、反常积分、积分中值定理
❌ 🔴 非教材章节，答辩会被问到，担心的话直接删掉此项
```

🔴 不要写 emoji、markdown 标记，也不要写给人看的操作备注 —— 模型读不懂「删掉此项」，
却可能被「非教材」「建议」这类词带偏归类。给人看的说明写在本文档里。

## 顺序

数组顺序只影响两件事：界面上的展示顺序、提示词里候选列表的先后。
**不影响归类结果，也不影响掌握度统计** —— 归类靠 `brief` 的内容匹配，与位置无关。

如果之后想把顺序整理成教材次序，大致是：前 6 项属上册；下册依次为
空间解析几何 → 多元函数微分法 → 重积分 → 曲线积分与曲面积分 → 无穷级数。
「微分方程」的位置随版次不同（第六/七版在上册末章），请以手头教材目录为准。

当前数据未按此重排 —— 既然不影响功能，等有人要改界面展示时再动。

## 两个设计选择

- 教材里「微分方程」是一章，这里按难度拆成 `ch_ode_basic`（一阶）和
  `ch_ode_higher`（高阶）两个抽屉，便于掌握度分层。
- `ch_math_modeling`「微积分综合应用」**不是教材章节**，是扩展抽屉，用于挂跨章节综合题。
  不需要跨章节抽屉的话，删掉它即可（其余条目不受影响）。

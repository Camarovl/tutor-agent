# data/chapters.json 说明

🔴 **这不是知识点库**，只是 15 个归类抽屉的名字。具体知识点（洛必达法则、分部积分法…）
由系统在问答和错题归类时通过 `find_or_create()` 自动创建并挂到这里。

设这个上限的唯一原因：不给顶层分类设边界，AI 会造出「极限」「函数极限」「求极限」
「洛必达」这种粒度并列的条目，掌握度统计随即作废。

## id 命名规范

```
格式：ch_<英文关键词>
规则：全小写、下划线分隔、不用中文
```

🔴 id 出现在数据文件 / 表结构 / 提示词 / 校验器四处，中途改名代价极大 —— 上线后不再改。

## 顺序与版次

表格顺序按同济版《高等数学》教材相对次序：上册 1~6，下册从第 7 项
「空间解析几何与向量代数」开始。各章阿拉伯数字编号请以实体书版权页为准。

两点说明：
- 教材里「微分方程」是一章，这里按难度拆成 12、13 两个抽屉（便于掌握度分层）。
- 第 15 项「微积分综合应用」**不是教材章节**，是扩展抽屉，用于挂跨章节综合题。
  不需要跨章节抽屉的话，直接删掉它。
